# سایت شخصی مجتبی کلانتری

این پوشه نسخهٔ آمادهٔ سایت شخصی شما برای GitHub Pages است. طراحی و محتوا انگلیسی است و روی موبایل و کامپیوتر نمایش داده می‌شود. فایل‌های سایت مستقل هستند و نصب نرم‌افزار یا خرید هاست لازم ندارند.

## فایل‌ها

- `index.html`: تمام طراحی، متن‌ها، تصاویر برداری و قابلیت‌های سایت.
- `cv.pdf`: رزومهٔ عمومی قابل‌دانلود، تهیه‌شده از رزومهٔ موجود شما. شمارهٔ تلفن و اطلاعات تماس معرف‌ها در آن درج نشده است.
- `.nojekyll`: برای انتشار مستقیم فایل‌های سایت.
- `README_FA.md`: همین راهنما؛ می‌توانید آن را در مخزن نگه دارید.

برای دیدن سایت روی کامپیوتر، پس از خارج‌کردن فایل ZIP از حالت فشرده، `index.html` را باز کنید. فایل `cv.pdf` باید کنار آن بماند تا دکمهٔ دانلود رزومه کار کند.

## انتشار رایگان در GitHub Pages

۱. به [GitHub](https://github.com/) وارد شوید. اگر حساب ندارید، یک حساب رایگان بسازید. نام کاربری در نشانی نهایی سایت به کار می‌رود.

۲. یک مخزن جدید با نام دقیق `USERNAME.github.io` بسازید. به‌جای `USERNAME` نام کاربری واقعی گیت‌هاب خودتان را با حروف کوچک بگذارید. مثلاً برای نام کاربری فرضی `example`، نام مخزن `example.github.io` خواهد بود.

۳. حالت مخزن را **Public** انتخاب کنید. برای این سایت حساب رایگان کافی است.

۴. فایل ZIP را روی کامپیوتر از حالت فشرده خارج کنید. در صفحهٔ مخزن، **Add file → Upload files** را انتخاب کنید. اگر مخزن خالی است، پیوند **uploading an existing file** را انتخاب کنید.

۵. فایل‌های داخل پوشه را بارگذاری و **Commit changes** را بزنید. خود ZIP یا پوشهٔ حاوی فایل‌ها را به‌عنوان یک زیرپوشه بارگذاری نکنید؛ `index.html` باید در صفحهٔ اصلی مخزن باشد، نه در یک پوشهٔ اضافه.

۶. وارد **Settings → Pages** شوید. در قسمت **Build and deployment**، گزینهٔ **Deploy from a branch** را انتخاب کنید. شاخهٔ **main** و پوشهٔ **/(root)** را تنظیم و **Save** را بزنید.

۷. منتظر بمانید تا انتشار کامل شود. طبق راهنمای گیت‌هاب، انتشار تغییرات می‌تواند تا ده دقیقه طول بکشد. نشانی سایت در همین بخش کنار **Visit site** نمایش داده می‌شود و شکل آن `https://USERNAME.github.io/` خواهد بود.

۸. سایت را باز کنید و معرفی، پروژه‌ها، عنوان مقاله و دکمهٔ دانلود رزومه را بررسی کنید. پس از هر ویرایش بعدی و ثبت تغییرات، سایت دوباره منتشر می‌شود.

راهنمای رسمی: [ایجاد سایت GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) و [تنظیم منبع انتشار](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## ویرایش‌های بعدی

برای تغییر متن‌ها می‌توانید در گیت‌هاب فایل `index.html` را باز کنید، دکمهٔ مداد را بزنید، متن موردنظر را تغییر دهید و **Commit changes** را انتخاب کنید. اگر راحت‌تر هستید، تغییرات دلخواه را بگویید تا فایل به‌روزشده آماده شود.

برای تعویض رزومه، فایل جدید را با نام `cv.pdf` جایگزین کنید. این نام را حفظ کنید تا پیوندهای دانلود سایت کار کنند.

عنوان و وضعیت مقاله از رزومهٔ موجود با تاریخ ۲۳ اکتبر ۲۰۲۶ برداشت شده است. پس از تغییر وضعیت مقاله، متن بخش Publications و رزومه را به‌روزرسانی کنید. تصاویر فنی سایت طرح‌های مفهومی هستند و عکس نمونهٔ ساخته‌شده یا خروجی اندازه‌گیری نیستند. می‌توانید بعداً تصاویر واقعی پروژه‌ها و عکس پرسنلی دلخواهتان را اضافه کنید.

استفاده از نشانی رایگان `github.io` هزینه‌ای ندارد؛ خرید دامنهٔ شخصی برای انتشار این سایت ضروری نیست.
